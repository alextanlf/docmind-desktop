# DocMind

DocMind 是一个运行在 macOS 本机的个人知识库助手。它把网页、PDF、Markdown 和语雀文档集中到一个地方，让你可以浏览、整理和提问，并且每个回答都尽量带上来源引用。

## 它能做什么

- 导入网页、PDF 和 Markdown 文件
- 连接语雀仓库，浏览和同步文档
- 建立本地索引，快速检索资料
- 基于你的资料回答问题，并显示引用来源
- 选择云端模型或本地 Ollama 模型

## 适合谁

适合希望把分散资料整理成私人知识库的个人用户，尤其是经常阅读长文、处理 PDF、使用语雀，并且希望回答可追溯的人。

## 支持的内容

| 类型     | 说明                         | 限制                        |
| -------- | ---------------------------- | --------------------------- |
| 网页     | 通过 HTTP/HTTPS 链接导入文章 | Markdown 转换后不超过 20 MB |
| PDF      | 导入本地 PDF                 | 单个文件不超过 100 MB       |
| Markdown | 导入 UTF-8 编码的 Markdown   | 单个文件不超过 20 MB        |
| 语雀     | 登录后同步已有仓库           | 需要完成语雀登录            |

## 快速开始

### 1. 准备环境

需要 macOS，以及：

- Node.js 20 或更高版本
- Python 3.11 或更高版本
- [uv](https://docs.astral.sh/uv/)

### 2. 安装依赖

在项目根目录执行：

```bash
npm install
./scripts/setup-backend.sh
```

### 3. 启动应用

```bash
npm run dev
```

### 4. 首次配置

启动后，在设置中选择模型服务，并填写 API Key。DocMind 支持 DeepSeek、Qwen、OpenAI 和自定义 OpenAI-compatible 服务。

API Key 只保存在 macOS Keychain 中，不会写入 SQLite、诊断信息或日志。

如果需要使用语雀，按应用提示完成语雀登录。第一次需要语义检索时，应用会提示准备 embedding 模型，下载体积约 400 MB。

## 使用本地模型

如果你希望使用本地模型，可以自行安装并运行 [Ollama](https://ollama.com/)，然后在 DocMind 的设置中选择本地模型。Ollama 只允许通过本机回环地址访问。

## 联网搜索

本地资料不足且开启联网搜索时，DocMind 按以下顺序尝试：

1. **模型内置联网**：Qwen（阿里云百炼）、OpenAI 等已配置的模型自带联网能力，无需额外配置
2. **Tavily**：在设置中填写了自己的 Tavily API Key 时使用
3. **SearXNG（可选）**：在设置的高级选项中填写自建实例地址后启用，需要实例在 `settings.yml` 中开启 JSON 输出（`search.formats` 加上 `json`）
4. **免费兜底**：Bing → DuckDuckGo，无需配置；命中后会抓取前几条结果的网页正文作为证据，稳定性和结果质量一般

搜索结果会作为引用来源展示，并可以挑选后加入知识库。DeepSeek 等不支持内置联网的模型会自动跳到下一级来源。

默认开启"智能改写搜索词"：DocMind 会先用当前模型把问题改写成最多 3 条查询词，并行检索后合并去重，提升召回。关闭后只检索原始问题，可以减少一次模型调用和额外的搜索请求。

## 隐私和数据归属

- 文档索引和缓存默认保存在本机应用数据目录
- API Key 仅保存在 macOS Keychain
- 开启联网搜索后（“自动”模式或确认联网时），应用会按“模型内置联网 → Tavily → SearXNG（已配置时）→ Bing/DuckDuckGo 免费兜底”的顺序访问搜索服务；免费兜底会抓取命中结果的网页正文（自动剔除导航、侧栏等噪声）；关闭联网搜索时不会访问
- 免费兜底的网页正文由本机直接抓取，目标网站会看到你的网络地址；不开启联网搜索时不会发生任何抓取
- 本地文件路径不会进入回答中的引用或持久化内容

## 常见问题

### 启动失败

先确认 Node.js、Python、uv 和项目依赖都已安装。如果提示端口被占用，通常是 `127.0.0.1:18900` 已被其他进程使用。

### 打开后显示后端不可用

检查后端依赖是否完整。必要时重新运行：

```bash
./scripts/setup-backend.sh
```

### 有可以下载的安装包吗

当前版本以本地开发方式运行，暂不提供签名后的 `.dmg` 或 `.app` 安装包。

## 开发者

运行完整检查：

```bash
npm run verify
```
